Neon Void is a neon arena-survival browser game: fly a lone ship through waves of drifters, darts, spitters and brutes, collect XP gems, pick level-up upgrades and hold the void as long as you can.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. No build step, no network requests: the whole game is static files under `game/`.

## How to play

- **WASD / arrow keys** — fly
- **Mouse** — aim (bolts fire on their own)
- **P / Esc** — pause, **M** — mute, **R** — restart after game over
- **1 / 2 / 3 or click** — pick a level-up upgrade

Waves get denser and tougher; brutes drop five gems; the best score is kept in your browser.
